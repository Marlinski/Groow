Anatomy

Groow is an organism with five organs: a body it lives in, senses it acts through, a limbic system that decides how things felt, a brain that answers, and a hippocampus that turns the day into changes in that brain. Each one is a directory in this repository.

1. The body

A read-only Docker image (CUDA, Python, the runtime under /opt, root-owned) and a home that is the whole of Groow: ./home on the host, the only writable place in its world. Weights, memory, identity, skills, packages, logs, all of it lives there and survives restarts, rebuilds and a move to another machine. Groow is an unprivileged user: no apt, no sudo, no way to alter its own runtime. It installs what it needs locally with Nix or uv. ./birth (or groow start) creates the home, builds the body if missing, and gives birth the first time; the entrypoint checks for a birth certificate and otherwise just wakes it. Details: Self-extension.

2. The senses

Three tools, and nothing else. Everything a richer agent would get as a tool is a file in the home or a command in the shell, because a small model chooses badly from a long menu and every schema costs prompt tokens.

SenseWhat it reaches
shell(command)the home, its files and traces, the commands its skills install (web <url>, news, tictactoe, arithmetic) and the groow … commands that reach its own daemon
think(goal)an inner thought: a second line of reasoning with its own history and its own shell, running concurrently
ask(question)the mentor's inbox, the one channel out that is not the conversation

Everything a sense does is written to the journal (state/main/, every message and every tool result, fsynced as it happens) and, for skills that play in bulk, to the activity log (state/log/activity.jsonl). Those two files are the only inputs the rest of the organism has. Details: Harness.

3. The limbic system

Nothing in the thinking part of an animal writes its own reward, so nothing here does either: there is no tool to rate a turn, and a skill cannot state its own score. Valence is computed from what happened, by two channels.

The judge covers what the sensors cannot read: how the person took it, and whether a command that exited cleanly actually did anything. It is a frozen System One model, Laya (421M, Apache-2.0, ~35 ms on CPU, so it never competes with the brain for the GPU), a reproduction of the Jev idea: state plus typed questions in, calibrated probabilities out, one forward pass, no text. Groow asks it two questions and uses the signed probability gap:

reaction(groow_said, person_replied) -> p(pleased) − p(displeased)
outcome(command, result)             -> p(useful)  − p(failed)

It is hypothalamic on purpose: it evaluates, it never learns, Groow cannot edit it, and a smaller GLiClass scorer or nothing at all can be swapped in (judge in groow.json). Measured on this machine it reads praise, corrections, repeated questions and complaints correctly, and calls an illegal move in a game a failure with no annotation anywhere.

Approval is late. You do not know whether what you said landed until the person answers, so a turn is held until the next human message and only then learned from. A turn nobody will react to (an idle impulse, a reminder, an inner thought reporting back) is finalised on sensors alone. Pain and pleasure accumulate with a half-life of thirty minutes: that is the mood the creature in the UI shows, and it is what drives sleep pressure.

4. The brain

A frozen fp16 base (Qwen3-4B-Instruct-2507, 262k context) plus a plastic overlay: LoRA on every linear projection, ~66M parameters in fp32, the only thing that moves. A generation server batches concurrent requests from the main thought and its inner thoughts into single forward passes and preempts a background batch per token when the person speaks. At night the overlay is merged into the base exactly and a blank one opens: short-term plasticity becomes long-term memory. Any weight change blocks inference, which is why it is shown as a nap. Details: Learning, Mind.

5. The hippocampus

It reads the logs and the valence and writes training sets (state/training/<set>.jsonl). It is the only thing that decides what is learned, and the trainer is the only thing that turns samples into gradients.

WhenWhat it preparesHow it is learned
nap, after every turnthe exchange, weighted by its valence (reinforced when it went well, pushed away when it went badly), and every tool call as a decision with its own creditsupervised step + policy gradient, with two replayed memories
idle napthe activity log: a game's moves and rewards, a drill's scored answersgrouped policy gradient (advantages normalised within a round)
nightfacts stated in the day's transcript or read from a page, kept only if quoted verbatim and still surprising to the weightssupervised, then replay, identity distillation, drift probe, merge

Because the credit lands on tool calls, the same machinery that learns a fact learns to use the shell: a command that failed is discouraged, the fix that followed it is reinforced, and getting better at an API Groow discovered this morning needs no new code. Details: Learning.
