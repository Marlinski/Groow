Groow

A small language model whose weights are not frozen. It learns from every conversation, drills itself on purpose, reads the news when nobody talks to it, thinks in the background, and sleeps to make what it learned permanent.

Base
Qwen3-4B-Instruct-2507
4.1B dense parameters, fp16, 262k context. Tesla V100S 32 GB.
Plastic
LoRA overlay, rank 32
66M fp32 parameters on every linear layer. This is what moves every turn.
Permanent
Consolidation
At night the overlay is merged exactly into the base and a blank one opens.
Grounded
Memory files
Episodes, lessons, thought traces. Rehearsal pool and searchable diary.

The four mechanics

PageWhat it covers
LearningPassive learning from every turn, active drills (memorize, quiz, self-play), sleep with replay and rollback, identity internalisation, drift probes, growth.
HarnessThe tool registry, the turn loop, the generation server that batches concurrent requests, built-in / self / sense tools, the sandbox.
Self-extensionSkills Groow writes for itself: sandbox check, install, rollback, quarantine; the supervisor, safe mode and groow doctor; why the core is only patched through review.
MindThe single conscious thread and its signal queue, inner thoughts as concurrent coroutines with their own traces, the lifecycle, recall of any past conversation.

Running it

uv venv --python 3.12 .venv && . .venv/bin/activate
uv pip install --index-url https://download.pytorch.org/whl/cu126 torch
uv pip install -e .
groow init      # copies the base model into state/, measures baseline probes
groow chat      # the conscious thread; it learns after every turn

# or sandboxed, state persisted in ./data
docker compose run --rm groow init
docker compose run --rm groow chat

Inside the chat: /good /bad rate the last answer, /sleep, /sense, /thoughts, /identity, /inbox, /stats, /quit. One-shot commands: groow memorize, quiz, play, sense, sleep, rollback, identity, probe, stats.
