Groow

A small language model whose weights are not frozen. It learns from every exchange, from commands that worked and commands that did not, and from whether anyone answered when it asked. At night what it practised is merged into the base and becomes what it is.

Base
Qwen3-4B
4.1B dense parameters, fp16. One Tesla V100S, which is Volta: fp16 only, cu126 wheels.
Plastic
LoRA overlay, rank 32
66M fp32 parameters on every linear layer. This is what moves.
Permanent
Consolidation
At night the overlay is merged exactly into the base and a blank one opens.
Felt
No self-annotation
Free sensors and a frozen judge decide how a turn went. Nothing rates itself.

The core is the only writer of state. The mind cannot edit its own history, because it has no handle on it: it asks, and the core decides. When the core runs as root the state directory is not writable by the mind at all, and when it is not root the core says so at startup rather than implying a guarantee it does not have.

Running it

git clone git@github.com:Marlinski/Groow.git && cd Groow
./birth              # builds the body, creates ./home, gives birth the first time
./birth ui           # the window onto it
./birth say "hello"
./birth stop

Without Docker: build the core with cargo build --release --manifest-path rust/Cargo.toml, install the learning side with uv pip install -e ., start the brain with python -m groow.serve, then groow start and groow ui.
