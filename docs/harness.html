Harness

Everything between a message and a finished turn: the tool registry, the turn loop, and the generation server that lets many conversations share one GPU. Plain Python, no framework, so Groow can one day edit it.

The turn loop

flowchart LR
  A[messages] --> G[complete via GenServer]
  G --> P[parse: think / content / tool_call blocks]
  P -->|tool calls| X[registry.call → JSON]
  X -->|tool_response| A
  P -->|no tool call| F[final text]
  F --> H[after_turn hook: learner.passive]

Harness.turn() is a coroutine. It renders the rolling history with the model's chat template (tool schemas included), awaits the generation server, parses Qwen's <tool_call> JSON blocks, executes each tool, appends the <tool_response>, and loops up to max_tool_rounds. Tools that train run on the GPU executor; I/O tools run on the default executor. If should_stop fires mid-generation the turn is rolled back and leaves no trace.

Rolling context. Before each generation the harness drops the oldest previous turns until the prompt fits max_seq_len − max_new_tokens. The current turn is never cut. The system prompt plus 16 tool schemas is about 1.7k tokens on every call.

The generation server

The in-process equivalent of a completions API. Coroutines call await server.complete(messages, tools, priority=…). One worker task drains the request queue and runs requests of the same class as a single left-padded batch on the GPU executor, the only thread that touches CUDA. Training steps use the same executor, so GPU jobs never collide.

flowchart TD
  M[main thought
priority 0] --> Q[request queue]
  T1[thought a
priority 2] --> Q
  T2[thought b
priority 2] --> Q
  Q --> W{worker}
  W -->|urgent present| S[serve main alone,
streaming to console]
  W -->|else| B[batch thoughts,
one forward pass]
  B -.->|urgent arrives mid-token| R[abandon batch, requeue]
  R --> S

Preemption is per token: during a thought batch the worker polls for a priority-0 request; if one arrives it raises Interrupted, the batch is re-queued untouched, and the main thought is served. You never wait for a background thought to finish a sentence.

The registry

A plain function becomes a tool by decoration. The JSON schema the model sees is derived from the signature (type hints, defaults) and the docstring (summary and an Args: section). Calls are dispatched by name with argument coercion; every error is returned to the model as JSON, never raised into the loop, so a bad call is something it can read and recover from.

@registry.tool(group="basic")
def word_count(text: str) -> dict:
    """Count words in a text.

    Args:
        text: the text to count
    """
    return {"words": len(text.split())}

Speaking to the person and to the mentor, rewriting the identity, sleeping and growing are main-thought privileges. Inner thoughts can learn (they change weights through learn_fact, memorize, play) but cannot communicate except through the main thought.

Sandbox

File tools cannot leave the workspace directory. run_python executes in a fresh subprocess with a timeout. Invented games are off by default because they execute model-written code in-process. The Docker image (Dockerfile, docker-compose.yml) runs everything under /data mounted from ./data, with the GPU passed through CDI.
